"# GestorBibliotecaV2" 

Sistema Monolítico desarrollado en Python con Framework Django, con arquitectura MVT, diseño modular en multicapa.
su templates esta realzado con Html y Bootstrap
Gestor Biblioteca es un sistema WEB; posee un control de inventario de Libro, registro de usuarios, login de acceso con perfiles de control (user/admin), posee una capa publica y otra con acceso restringido a usuario registrados que puede pedir/devolver libros.

Se deja abierto a futuras mejoras como una V3
